# Raw data

Place these IBM Telco Customer Churn files in this folder:

- `Telco_customer_churn_demographics.xlsx`
- `Telco_customer_churn_location.xlsx`
- `Telco_customer_churn_population.xlsx`
- `Telco_customer_churn_services.xlsx`
- `Telco_customer_churn_status.xlsx`

Do not rename the files if you want the provided loader to work without changes.

Source directory:
https://public.dhe.ibm.com/software/data/sw-library/cognos/mobile/C11/data/

Raw `.xlsx` files are intentionally ignored by Git in this project. Keep the source data local and commit only code/documentation unless the course requires otherwise.
