# Report Figure Capture Plan

Mỗi milestone phải tạo/ghi nhận hình theo danh sách trong `reports/report.docx`.

## Quy tắc

1. Hình chứng minh kết quả phải được lưu dưới `outputs/`.
2. Tên file dùng mã Fxx ổn định, không đổi giữa các lần chạy.
3. Hình notebook phải thể hiện ngữ cảnh: tiêu đề bước + output quan trọng.
4. Hình Dashboard phải có ít nhất: overview, filters, drill-down/cross-filter.
5. Sau mỗi milestone: cập nhật `reports/report.docx`, caption và nhận xét ngay.
6. Không ghi số liệu minh họa thành số liệu chính thức.

## Milestones

- F02–F03: Notebook 01 — inspection + key validation.
- F04–F06: Notebook 02 — cleaning, Join, feature engineering, outlier evidence.
- F07–F10: Notebook 03 — 4 EDA charts.
- F11–F13: Streamlit Dashboard — overview + interaction.
- F14–F17: Notebook 04 — model metrics, confusion matrix, risk scoring.
- F00/F01: diagrams maintained in report.
